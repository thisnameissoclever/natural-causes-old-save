Move your Natural Causes save

Natural Causes is now at natural-causes.life. Browsers keep saved games separately for each web address, so a game saved at the old address does not appear there by itself.

  1. Open this page in the browser and on the device where you played before. Do this soon: some browsers, including Safari, can clear saved data for a site you have not visited for a while.
  2. Choose Download save.
  3. Open natural-causes.life, open Options, choose Import save, pick the downloaded file, then choose Import game.

This page reads the saved game in this browser and leaves it unchanged.
