# Natural Causes: move an old saved game

Natural Causes moved from `thisnameissoclever.github.io/terrilives/` to [natural-causes.life](https://natural-causes.life/). Browsers store saved games separately for each web address, and the old address now redirects, so players cannot open the old game to export a save.

This page is served from the old web address (`thisnameissoclever.github.io`), so it can read the saved game that the old game stored in the browser. It downloads that save as a `.ncsave` file, which the game's Options > Import save accepts at the new address. It never changes or removes the stored save.

Published at <https://thisnameissoclever.github.io/natural-causes-old-save/>. The game's source is in [thisnameissoclever/terrilives](https://github.com/thisnameissoclever/terrilives).
